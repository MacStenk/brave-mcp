# Security Policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting (Security tab → "Report a
vulnerability"). Please do not post security issues publicly.

This is a one-person project; reports are answered as fast as possible, typically
within a few days. Fixes ship as patch releases and credit the reporter.
Which versions receive security fixes is listed under
[Supported versions in RELEASES.md](RELEASES.md#supported-versions).

Scope note: this server drives the browser you are already logged into. Treat any
way to make it act outside the documented tools as a reportable issue.
